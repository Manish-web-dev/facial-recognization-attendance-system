HOW TO PUSH THIS PROJECT TO GITHUB
===============================================================================

Prerequisites
- Install Git: winget install --id Git.Git -e (or download from git-scm.com)
- Verify: git --version
- Sign in to GitHub.

1) Create a new repository on GitHub
- Name: facial-recognization-system (or any name)
- Visibility: public/private
- Do NOT initialize with README/.gitignore.
- Copy the HTTPS URL (e.g., https://github.com/<your-user>/<your-repo>.git)

2) Initialize Git in the project folder
- Open PowerShell in:
  D:\BACHELOR\college project\Facial Recognization system
- Run:
  git init
  git branch -M main

- Optional: Set user config (skip if already set globally):
  git config --global --list
  If user.name and user.email are missing, run:
    git config --global user.name "Your Name"
    git config --global user.email "you@example.com"

3) Optional: ignore generated files
- Create a .gitignore (recommended entries):
  .venv/
  __pycache__/
  *.pyc
  *.pyo
  *.pyd
  .DS_Store
  .idea/
  .vscode/
  .env
  *.log

4) Stage and commit
- Run:
  git add .
  git commit -m "Initial commit"

5) Connect remote and push (HTTPS)
- Run:
  git remote add origin https://github.com/<your-user>/<your-repo>.git
  git push -u origin main
- On first push, use a GitHub Personal Access Token (PAT) as the password:
  GitHub > Settings > Developer settings > Personal access tokens > Generate
  Scope: repo (or fine-grained equivalent)

Alternative: SSH (no PAT on push)
- Generate key:
  ssh-keygen -t ed25519 -C "you@example.com"
- Start agent and add key:
  Start-Service ssh-agent
  ssh-add $env:USERPROFILE\.ssh\id_ed25519
- Add id_ed25519.pub to GitHub > Settings > SSH and GPG keys.
- Set remote and push:
  git remote add origin git@github.com:<your-user>/<your-repo>.git
  git push -u origin main

GitHub Desktop (GUI path)
- File > Add local repository > Select "D:\BACHELOR\college project\Facial Recognization system"
- Click "Publish repository" to GitHub
- Commit and Push from Desktop.

Troubleshooting
- Remote has README and push is rejected:
  git pull origin main --allow-unrelated-histories
  git push
- Pushed wrong files (e.g., .venv):
  git rm -r --cached .venv
  echo ".venv/" >> .gitignore
  git add .gitignore
  git commit -m "Ignore venv"
  git push
- Default branch mismatch:
  git branch -M main
  git push -u origin main

- Add id_ed25519.pub to GitHub > Settings > SSH and GPG keys.
- Set remote and push:
  git remote add origin git@github.com:<your-user>/<your-repo>.git
  git push -u origin main

- Click "Publish repository" to GitHub

===============================================================================
TROUBLESHOOTING GITIGNORE ISSUES
===============================================================================

Problem: .gitignore not working, files still tracked
Solution:
  git rm -r --cached .
  git add .
  git commit -m "Apply .gitignore rules"

Problem: Want to ignore file but it keeps showing in git status
Solution: File is already tracked. Remove it:
  git rm --cached filename
  git commit -m "Stop tracking filename"

Problem: Need to see what Git is ignoring
Solution:
  git status --ignored
  git check-ignore -v filename  # Check why specific file is ignored

Problem: Accidentally committed .venv/ to GitHub
Solution:
  git rm -r --cached .venv/
  echo ".venv/" >> .gitignore
  git add .gitignore
  git commit -m "Remove .venv from repository"
  git push --force  # Only if no one else is using the repo
